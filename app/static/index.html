语法说明
  • kN：消耗 N 针，产出 N 针（平针）
  • incN：消耗 1 针，产出 N 针（加针）
  • decN：消耗 N 针，产出 1 针（减针）
  • [指令序列]*M：将方括号内序列整体重复 M 次，可嵌套，如 [k2 inc1]*3 [k3 dec2]*2
  • [指令序列]*~N：自适应重复，按顺序重复方括号内序列，直到本行恰好剩余 N 针供后续指令使用（N 为非负整数）；实际重复次数在展开前按当前剩余针数推导，(当前剩余 − N) 必须能被每轮消耗针数整除。如 [k2]*~4 k4（20 针时重复 8 次、留 4 针给 k4）。自适应块只能位于行内顶层，其内部可嵌套固定次数块（如 [[k2]*2 inc1]*~5）。
  • 每行的可用针数 = 上一行产出；针数不足时报“短缺”，未全部消耗报“未消耗”。
  • 通过 / 未全部消耗的行附带「针数变化来源」清单：按源文本中每处 incN / decN 汇总实际执行次数、消耗 / 产出针数与净变化，点击条目可在源指令中定位。
